 ML-Classification-Models
A comprehensive implementation of Supervised Machine Learning algorithms using Python and Scikit-Learn. This repository includes end-to-end workflows for Classification (Decision Tree, KNN, SVM, Logistic Regression) and Regression (Random Forest), focusing on data preprocessing, model training, and performance evaluation.

This repository showcases various supervised learning algorithms implemented using Python and Scikit-Learn.

 📁 Project Structure

🔍 Classification Models
  Decision Tree: Species classification using the Iris dataset.
  K-Nearest Neighbors (KNN): Medical diagnostic prediction (Malignant/Benign).
  Support Vector Machine (SVM): Handwritten digit recognition.
  Logistic Regression: Probabilistic classification for flower species.

 Regression Models
  Linear Regression: Predicting house rent prices and student marks based on study hours.
  Random Forest Regression: Advanced ensemble methods for numerical prediction.

Technologies Used
  Language: Python
  Libraries: Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn
  Environment:Jupyter Notebook
